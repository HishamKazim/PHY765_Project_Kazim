# TiO2 Quantum Resource Estimation

Full-stack fault-tolerant quantum resource estimates for photocatalytic
wastewater treatment on Ti2O4 clusters derived from anatase TiO2.

## Problem statement

Photocatalytic wastewater treatment uses photocatalysts, most
commonly TiO2, to break down emerging contaminants (dyes, pharmaceuticals,
pesticides) under UV light. Predicting which dopants, surface
modifications, and reaction conditions yield the best photocatalytic activity
requires accurate electronic-structure simulation of strongly correlated Ti 3d
and O 2p manifolds. Classical full configuration interaction scales
combinatorially with active-space size and is infeasible to solve after 20 orbitals.
Density functional theory is a method that is applied to many-body systems but it has issues related to correlations in orbital levels with accuracy on transition metals being a potential issue in obtaining accurate results.

This repository quantifies the fault-tolerant quantum resources required to
solve the electronic-structure problem for a Ti2O4 anatase within
chemical accuracy of 1.6 mHa as outlined in the literature using qubitized quantum phase estimation. Three
block encodings are compared (PauliLCU, double factorization, tensor
hypercontraction) across six active spaces from (4e,4o) to (24e,24o), with
surface-code overhead computed at three physical error rates (1e-3, 1e-4,
1e-5). Results are extrapolated to regions of 50-100 orbitals such that it is meaningful. The results are compared against FeMoco to estimate the current range of this molecule and how it compares with other molecules following a similar methodology. 

## Installation

Clone the repository and install dependencies into a fresh Python 3.10+
environment:

```bash
git clone https://github.com/HishamKazim/PHY765_Project_Kazim.git
cd tio2_qre
python3.11 -m venv venv
source venv/bin/activate         
pip install -r requirements.txt
```


## Quickstart

Reproduce every figure and table with one command:

```bash
python scripts/regenerate_figures.py
```

This runs all six notebooks in order and writes results to `data/` and the
summary plot to `figures/scaling_summary.png`. Total runtime is ~10 minutes
on a modern laptop.

To explore in-depth, launch Jupyter and open the notebooks in order:

```bash
jupyter notebook
```

## Configuration

All parameters live in `config.yaml`:

- System geometry, basis set, charge, spin
- Active-space sweep (electrons, orbitals, labels)
- QPE target precision and synthesis precision
- THC rank multiplier and lambda compression factors
- Surface-code parameters and physical error rates

Edit `config.yaml` and rerun `regenerate_figures.py` to regenerate all
results with different parameters.

| Notebook | Purpose |

| 02 | PauliLCU |
| 03 | Double factorization  |
| 04 | Tensor hypercontraction |
| 05 | Full configuration interaction on (12e,12o) to verify HF correlation gap exceeds 1.6 mHa |
| 06 | Surface-code overhead, scaling fits, classical-quantum crossover, FeMoco benchmark, extrapolation, summary plot |

## Key results

- Classical-quantum crossover: 25 orbitals (LCU/DF), 20 orbitals (THC)
- (12e,12o) target with THC at p=1e-3: ~70k physical qubits, roughly 3 hr wall time
- 50-orbital chemically realistic target with THC at p=1e-3: at 240k physical qubits and takes 11 days if extrapolation is accurate beyond the active space range.
